# Biblioteca-de-Alexandria-do-Manfrine
Sistema de biblioteca desenvolvido para a matério de POO por conta de um trabalho envolvendo JFrame, uma biblioteca antiga de Java utilizada para a criaçao de interfaces gráficas. Trabalho desenvolvido pelos alunos Lucas Roque e Ítalo Pereira, além da apresentação de Paulo Gabriel.

Tecnologias utilizadas:
-Linguagem de programação 
Java
-Bibliotecas
Java Swing
Java AWT
-Estrutura de dados
ArrayList
DefaultListModel
-Ferramentas
IntelliJ
Git+GitHub
